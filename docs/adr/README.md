# 設計判断の記録（ADR）

後から「なぜこうなっているのか」を問われる判断を、判断した時点の事実と一緒に残す場所。

- 1件1ファイル。番号は連番で、一度振った番号は再利用しない。
- 状態は **提案 → 承認 / 却下**。承認後に判断を変えるときは、元のファイルを書き換えず、新しい ADR を起こして「置き換え」と書く。
- 書くことは「決めること」「その時点の事実（根拠へのリンク付き）」「決定」「採らなかった案とその理由」「結果（良くなること・払うもの）」。
