## A. 本人への説明

### この研究について

blescという記録アプリを使って、**高校生が毎日どんなことを書き、そのときどんな気持ちだったかを集める研究**です。集めたデータは、将来「気持ちの変化を早めに見つける仕組み」をつくれるかどうかを調べるために使います。

期間は**21日間**です。

### あなたにお願いすること

1日1回、アプリを開いて

- その日のことを、書きたいだけ書く（1行でも、書かない日があってもかまいません）
- 5つの質問に答える（気分、ストレス、睡眠の質、睡眠時間、出来事の大きさ）

質問は**毎日同じ**で、どれも**答えなくてかまいません**。

### この期間、AIは何もしません

ふだんのblescには、書いた内容をAIが読み取って返す機能があります。**この研究の21日間は、その機能をすべて止めます。**

- あなたが書いた文章は、OpenAIなどの外部のサービスに送りません。
- AIからの返事やアドバイスは表示されません。
- あなた用のグラフや分析結果も表示されません。

理由は2つあります。**AIの読み取りを見ると書き方が変わってしまうから**と、**まだ十分に検証していないAIの出力を、あなたに返したくないから**です。

### だれが読むか

| 誰 | 何を見るか |
| --- | --- |
| 研究チーム | 仮名（ランダムな記号）にした状態のデータ |
| 学校の先生 | **あなたが書いた文章は見ません。** 参加人数や提出状況だけ |
| 保護者 | **あなたが書いた文章は見ません。** 参加の確認だけ |

原文の保存に同意した記録は、運営者が平日10時・16時（日本時間）に目視確認します。夜間・休日は確認せず、危機の発見や救助は保証できません。原文の保存に同意しない場合は、後から内容を確認できません。**自分や誰かを傷つけそうな内容**を確認した場合は、学校の相談窓口につなぐことがあります。緊急時はアプリの確認を待たずに119／110または学校の相談窓口へ直接連絡してください。

### 参加は自由です

- 参加しなくても、**成績・評価・進路に一切関係ありません。**
- 途中でやめられます。**理由を言う必要はありません。**
- やめたあとに不利益はありません。
- 一度書いたものを消してほしいときは、消せます（§F）。

### 記録について

- 書いた文章は暗号化して保存します。
- 書いた文章を保存することに同意した場合、各記録から最長90日保存します。仮名化した研究データは研究終了後1年、本人との対応表は終了後90日を上限とします。削除依頼については§Fを参照してください。公表済みの個人を識別できない集計は取り消せません。
- あなたの名前・住所・電話番号・学籍番号は集めません。

### AIの学習に使うかどうか

書いた文章をAIの学習に使うかどうかは、**参加とは別に選べます**。「使ってよい」を選ばなくても、研究には普通に参加できます。既定は「使わない」です。

### 質問したいとき

研究問い合わせ先: **blesc.jp@gmail.com**（2026-09-18、project owner指定）。研究用IDだけを記載し、本文・診断情報・パスワード・確認用リンクは送らないでください。緊急時の窓口ではありません。

受付は平日10:00–17:00（日本時間）、受付確認は3営業日以内を目標とします。**緊急窓口ではありません。** 担当受諾・学校確認・到達試験が済むまで配布しません。

### 謝礼と結果共有

謝礼・金券・成績上の利益はありません。研究終了後、個人を識別できない全体要約を募集時に案内する公開ページへ載せ、学校経由でも閲覧先をお知らせします。個人ごとの結果は返しません。公開ページと予定時期は募集前に確定します。

## B. 本人の同意

以下は**それぞれ別に**選びます。まとめて1つのチェックにしません。

| # | 項目 | 保存先 | 既定 |
| --- | --- | --- | --- |
| 1 | 上の説明を読み、わからないところは質問できました | — | — |
| 2 | このアプリを研究期間中に使うことに同意します | `consent_records.app_use` | いいえ |
| 3 | 書いた内容を研究の分析に使うことに同意します | `consent_records.research_analysis` | いいえ |
| 4 | 書いた文章そのものを保存することに同意します | `consent_records.raw_text_retention` | いいえ |
| 5 | （任意）書いた文章をAIの学習に使うことに同意します | `model_training_use`（**未実装**） | いいえ |

- 2と3に同意しない場合、研究には参加できません（アプリの通常利用は妨げません）。
- 4に同意しない場合も参加できます。その場合、文章そのものは保存せず、集計に使う数値だけを保存します。
- 5はいつでも取り消せます。取り消し後は学習に使いません。

18歳未満の場合、**この同意だけでは参加は始まりません。** 保護者の確認（§D）が別に必要です。

## C. 保護者への説明

### お子さまへのご依頼

blescという記録アプリを使い、**21日間、1日1回の記録と5つの質問への回答**をお願いする研究です。高校生が日々どのように状況を記述するかの基礎データを集めます。

### 収集するもの・しないもの

| 収集します | 収集しません |
| --- | --- |
| 自由記述（本人が書きたいだけ） | 氏名・住所・電話番号・学籍番号 |
| 5項目の自己評定（すべて任意） | 位置情報 |
| 入力にかかった時間などの操作記録 | 端末の連絡先・写真・他アプリの利用状況 |
| | 医療・診断・服薬に関する直接の質問 |

### この期間、AIによる応答は行いません

研究期間中は、AIによる読み取り・応答・助言・分析表示をすべて停止します。本文を外部のAIサービスへ送ることもありません。未検証のAI出力を未成年者に返さないための措置です。

### 結果の扱い

- 研究チームが扱うのは仮名化したデータです。
- **学校の教職員は本文を閲覧しません。** 参加状況の集計のみを扱います。
- **保護者の方も本文を閲覧できません。** お子さまが書いたものは、お子さまのものです。
- 個人ごとの分析結果は、本人・保護者・教職員のいずれにも返しません。

原文保存に同意した記録は平日10時・16時（日本時間）に運営者が目視確認します。夜間・休日の確認はなく、危機の発見や救助は保証できません。原文保存への同意がなければ後から確認できません。自傷・他害など急迫した危険を覚知した場合、学校の相談体制へつなぐことがあります。緊急時は本人が119／110または学校の相談窓口へ直接連絡してください。

### 参加は任意です

- 参加・不参加は成績・評価・進路に一切関係しません。
- お子さま本人、または保護者の方から、いつでも撤回できます。理由は不要です。
- 撤回後のデータの扱い（残す／削除する）は選べます。

### 保持と削除

- 本文は暗号化して保存します。
- 原文は各記録から最長90日、仮名化した研究データは研究終了後1年、本人との対応表は終了後90日を上限とします。公表済みの非識別集計は取り消せません。
- 削除のご依頼は §F の手順で承ります。

### お問い合わせ

研究問い合わせ先: **blesc.jp@gmail.com**。受付は平日10:00–17:00（日本時間）、受付確認は3営業日以内を目標とします。研究用IDだけを記載し、本文・診断情報・パスワード・確認用リンク・身分証は送らないでください。緊急時の窓口ではありません。担当受諾・学校確認・到達試験が済むまで配布しません。謝礼はありません。研究終了後に非識別の全体要約を募集時に案内する公開ページへ掲載します。

## E. 撤回

### 本人が撤回するとき

アプリの設定画面から「研究への参加をやめる」を選びます。理由の入力欄は置きません。

撤回した時点で、

- 以降の記録は研究データとして保存されません。
- 撤回後の書き込みはexportに含まれません。
- 通常のアプリ利用は続けられます（続けるかどうかも自由です）。

### 保護者が撤回するとき

保護者またはアプリを使えない本人は、`blesc.jp@gmail.com` または学校の指定担当者へ申し出ます。メールは受付のみとし、既知の学校経路またはログイン済み経路で本人確認を行います。原文・診断情報・パスワード・確認リンク・身分証はメールに送らないでください。本人確認済みの撤回は1営業日以内に研究利用を停止することを目標とします。

### すでに集めたデータ

撤回時に選べます。

- **残す**: それまでのデータを分析に使います。
- **削除する**: §F の削除手順に進みます。

どちらを選んでも不利益はありません。

## F. 削除依頼

### 手順

1. 本人または保護者が、§E のメールまたは学校指定担当者へ削除を依頼する。
2. データ管理責任者が本人確認を行う。
3. 対象データを削除し、削除の事実と日時を記録する。
4. 依頼者へ完了を通知する。

### 削除されるもの・されないもの

| 削除される | 削除されない |
| --- | --- |
| 自由記述の本文（暗号化列を含む） | 削除を行ったという記録そのもの |
| 自己評定の回答 | 集計済みで個人を特定できない統計値 |
| 操作記録 | すでに公表された研究結果 |
| 仮名IDと本人の対応表 | |

すでに公表した集計結果から個人の寄与を取り除くことはできません。**この点は説明文（§A・§C）に書いておく必要があります。** 削除できると説明してからできないと伝えるのは、最も避けるべき順序です。

### 期限

受付確認は3営業日以内、本人確認後の稼働系対象データの削除は30日以内を目標とします。完了日時・対象・実行者・検証結果を本文なしで記録し、依頼者へ知らせます。バックアップ内の残存期間は実設定を確認して別途説明し、復旧時には削除を再適用します。
