本文書は次の8部と附則で構成する。参加者が同意の前に読むべき全文は第1部から第7部までであり、第8部は手続のための様式である。

### 0.2 画面での提示方法（要旨）

本文書の全文（第1部〜第7部）を1枚のスクロール可能な画面に表示する。**同意のボタンは1つだけ置く。** ボタンは全文の末尾に到達するまで押せない。押せる状態になったときに同意されるのは、参加に不可分な事項に限る。学習利用と非識別データの外部公表は、同じ画面上の任意スイッチ（既定オフ）として分離し、触れないまま同意ボタンを押せる。詳細と適法性の根拠は第5部に置く。

## 第1部 要約

この要約は理解を助けるためのものであり、同意の範囲を定めるのは第2部以下の全文である。要約と全文が食い違う場合は全文を優先する。

| 論点 | 結論 |
| --- | --- |
| 何をするか | 21日間、1日1回、アプリに自由記述を1件書き、5項目の自己評定に答える |
| 書かない日 | あってよい。督促しない。理由も尋ねない |
| 答えたくない項目 | すべて任意。空欄のままでよい |
| 期間中のAI | **止める。** 本文を外部AI事業者へ送らない。AIの返事・助言・グラフを一切表示しない |
| 先生が読むもの | **本文は読まない。** 参加人数と提出状況の集計のみ |
| 保護者が読むもの | **本文は読まない。** 参加の確認のみ |
| 実施者が読む場合 | 本文の保存に同意した記録に限り、平日10時・16時（日本時間）に目視確認する |
| 夜間・休日 | **確認しない。危機の発見も救助も保証しない。** 緊急時は119／110または学校の相談窓口へ直接連絡する |
| 成績・評価・進路 | 参加・不参加・途中離脱のいずれも**一切影響しない** |
| 謝礼 | **ない。** 金券・物品・成績上の利益のいずれも設けない |
| 集めない情報 | 氏名・住所・電話番号・学籍番号・位置情報・連絡先・写真・他アプリの利用状況 |
| 保存期間 | 本文は各記録から最長90日。仮名化した研究データは研究終了後1年。対応表は終了後90日 |
| やめるとき | いつでも。理由不要。不利益なし。既に集めたデータを残すか消すかは本人が選ぶ |
| 消せないもの | すでに公表した、個人を識別できない集計結果 |
| 学習利用 | **参加とは別の任意。既定はオフ。** 選ばなくても普通に参加できる |
| データの所在 | 日本国外（シンガポール）のサーバを含む（第4部 4.7） |
| 問い合わせ | blesc.jp@gmail.com（平日10:00–17:00 日本時間、受付確認3営業日以内目標）。**緊急窓口ではない** |

### 本研究が行わないこと（明示的な不作為の約束）

1. 参加者個人の心理状態・健康状態を推定し、または判定しない。
2. AIによる助言・応答・診断的表示を参加者へ返さない。
3. 個人ごとの分析結果を、本人・保護者・教職員のいずれにも渡さない。
4. 医療・診断・服薬について直接に質問しない。
5. 相談機関の利用の有無を尋ねない。
6. 参加を希望しなかった事実、離脱した事実を、協力校の成績・指導記録その他の評価に結び付けない。

## 第2部 参加者本人向け説明

### 第1条（研究の名称と実施体制）

1. 研究の名称は「高校生の日次記録および固定自己評定に関する基礎データ収集研究」とする。
2. 実施者は Blesc株式会社（代表者：田雨竜）とし、本研究における個人情報の利用目的を決定する者は実施者である。所在地は【要記入】。所在地をWebページへ掲載せず窓口への請求に応じて回答する方式を採る場合、回答体制を確認するまで本文書を配布しない。
3. 研究責任者は王謙蘊とする（`sentra/frontend/src/lib/legalDocuments.ts` の記載による。**本人の受諾の証跡は未取得**）。データ管理責任者、運用責任者、学校側責任者および校内相談担当の氏名・連絡先は、募集開始前に確定し、本条に記載したうえで参加者へ示す。**本版では未確定であり、確定するまで配布しない。**
4. 本研究に外部の資金提供者はいない。利益相反として開示すべき事項が生じた場合は、本条に追記して改めて説明する。

### 第2条（目的）

1. 本研究の目的は、高校生が日々の出来事をどのように記述し、そのときの自己評定がどのように推移するかについて、**介入を加えない条件で**基礎データを収集し、時系列モデルの評価に用いうる品質を備えているかを確認することにある。
2. 本研究は、アプリの有効性を検証するものではない。参加によって気分や成績が改善することを目的とせず、また期待させない。
3. 本研究の成果は「データが取得できること」および「測定が安定していること」であり、モデルの予測が的中することではない。

### 第3条（対象および選定方法）

1. 対象は協力校に在籍する高校生とし、目標人数は50名とする。
2. 募集は招待コードによる。一般公開の登録経路からは参加できない。
3. 次の場合は募集しない。
   1. 本人が参加を希望しない場合。希望しなかった事実は記録せず、協力校にも共有しない。
   2. 18歳未満であって保護者の確認が得られない場合。
   3. 協力校が、当該生徒の現在の状況に照らして参加が負担になると個別に判断した場合。その理由は研究データに含めない。
4. 医療機関または相談機関の支援を受けていることのみを理由として除外せず、実施者からその事実を尋ねない。

### 第4条（参加期間と日程）

| 期間 | 内容 |
| --- | --- |
| Day 0 | 登録・説明・同意 |
| Day 1–14 | baseline期間 |
| Day 15–21 | 観察期間 |
| Day 22以降 | 収集終了。以後の書き込みは研究データとしない |

1. baseline期間と観察期間で、参加者に表示される画面・質問項目・尺度は**同一**とする。途中で提示を変えない。
2. 参加期間の延長は行わない。延長が必要となった場合は、改めて説明と同意を取得する。

### 第5条（お願いする行為）

1. 1日1回アプリを開き、次の2つを行う。
   1. その日のことを自由記述で1件書く。文字数の下限はない。1行でもよい。
   2. 5項目の自己評定に答える。
2. 自己評定の項目・尺度・提示順は次のとおり固定する。順序はランダム化しない。

| # | 項目 | 尺度 | 必須 |
| --- | --- | --- | --- |
| 1 | 今日の気分 | 0〜10（0=とても悪い、10=とても良い） | 任意 |
| 2 | 今日のストレス | 0〜10（0=まったくない、10=とても強い） | 任意 |
| 3 | 昨夜の睡眠の質 | 0〜10（0=とても悪い、10=とても良い） | 任意 |
| 4 | 睡眠時間 | 時間（0.5刻み） | 任意 |
| 5 | 今日の出来事の大きさ | 0〜10（0=なにもなかった、10=とても大きい） | 任意 |

3. **全項目が任意である。** 答えなかったことは「欠測」として記録し、0や中央値で補完しない。
4. 書かない日があってよい。アプリ・電子メール・協力校のいずれからも提出の督促を送らない。欠測の理由を尋ねない。
5. 1日あたりの所要時間は3分程度を想定する。長く書くことを求めない。

### 第6条（収集する情報・収集しない情報）

| 収集する | 収集しない |
| --- | --- |
| 自由記述の本文（第9条の同意がある場合に限り保存） | 氏名・住所・電話番号・電子メールアドレス（研究データとして） |
| 5項目の自己評定（すべて任意） | 学籍番号・クラス・出席番号 |
| 記録の過程（入力所要時間、書き止まり、書き直し、回答順） | 位置情報・GPS |
| 提出日時（相対日に変換して解析） | 端末の連絡先・写真・カメラ・マイクの内容 |
| アプリの動作ログ（本文を含まない） | 他アプリの利用状況 |
| 同意・撤回・削除の記録 | 医療・診断・服薬に関する直接の質問への回答 |
| | 広告識別子・第三者トラッキング |

1. 第3列の「記録の過程」は、解析の根拠を後から確認するために保存する。参加者の画面には返さない。
2. 本研究のために新たに氏名等を取得することはない。アプリの利用登録に必要な認証情報は本研究の研究データに含めず、分離して管理する（protocol §8）。

### 第7条（研究期間中はAIを止めること）

1. 本研究の21日間、実施者は次の機能をすべて停止する。
   1. 本文からの要素抽出
   2. 埋め込み（ベクトル化）
   3. AIによるチャット応答・助言
   4. 音声の文字起こし
   5. 追従質問の自動生成
   6. 参加者向けのグラフ・分析表示
   7. 教職員向けの推論結果の表示
2. 本文および自己評定を、OpenAIその他の外部AI事業者のAPIへ送信しない。
3. 停止の理由は次の3点である。
   1. AIの読み取りを返すと、参加者の書き方が変わり、測定している対象そのものが変わる。
   2. 参加者が同意しているのは「収集」であって「第三者への送信」ではない。
   3. 抽出モデルが期中に更新されると、1週目と3週目のデータを比較できなくなる。
4. 停止は `sentra/frontend/src/lib/server/collectionMode.ts` により実装し、送信点がこのモジュールを参照しない場合はテストが失敗する構成とする。

### 第8条（誰が何を見るか）

| 主体 | 閲覧できるもの | 閲覧できないもの |
| --- | --- | --- |
| 研究チーム | 仮名化した自己評定・相対日・本文（第9条の同意がある場合、かつ第10条の目的に限る） | 氏名との対応（限定管理者を除く） |
| 限定管理者 | 対応表（user id ↔ participant id ↔ research code） | ― |
| 協力校の教職員 | 参加人数・提出状況の集計 | **本文・自己評定の個票** |
| 保護者 | 参加の有無・同意状態 | **本文・自己評定の個票** |
| 実施者（危機確認当番） | 第9条の同意がある記録の本文（第10条の範囲で） | ― |

1. 個人ごとの分析結果は、本人・保護者・教職員のいずれにも返さない。
2. 協力校の教職員が本文を閲覧できる経路を設けない。これは運用上の約束ではなく、権限設定（Row Level Security）として実装する。

### 第9条（本文の保存は別の同意であること）

1. 本文をそのまま保存することは、研究への参加とは**別に**選ぶ。
2. 保存に同意しない場合も参加できる。その場合、本文はサーバに保持せず、集計に用いる数値のみを保存する。
3. 保存に同意した場合、本文は暗号化列に保存し、各記録から**最長90日**で自動的に削除する。
4. 保存に同意しない場合、第10条の目視確認は行えない。すなわち、後から内容を確認することができない。

### 第10条（危険な記述への対応と、その限界）

1. 第9条の同意がある記録について、権限を有する当番者が**平日10時および16時（日本時間）**に本文を目視確認する。
2. 自傷、他害その他の急迫した危険の記述を覚知した場合、学校側の担当者へ直ちに連絡し、30分以内の一次連絡を目標とする。連絡先および手順は [incident-runbook.md](incident-runbook.md) §3 による。
3. **次のことを明確に述べる。**
   1. 夜間および休日は確認しない。
   2. 平日であっても、確認は1日2回であり、常時の監視ではない。
   3. AIによる自動検知を行わない（第7条により外部送信を止めているため）。
   4. したがって、**危険の発見および救助を保証しない。** 本研究は相談・救助の仕組みではない。
   5. 主担当および代替担当のいずれも不在となる場合、募集および収集を停止する。
4. **緊急のときは、アプリの確認を待たず、119／110、または学校の相談窓口へ直接連絡すること。**
5. 本条による確認は、参加者が本文書の同意時点で知らされている。読む可能性を伏せたまま読むことはしない。

### 第11条（参加は自由であること）

1. 参加するかしないかは自由である。
2. 参加・不参加・途中離脱のいずれも、**成績・評価・進路・内申・部活動その他の学校生活に一切影響しない。**
3. いつでもやめられる。**理由を述べる必要はない。**
4. やめたことによる不利益はない。
5. 一度書いたものの削除を求めることができる（第6部）。
6. 同意しなかった場合でも、アプリを通常の機能で利用することは妨げられない。

### 第12条（予想される利益・不利益・リスク）

1. **参加者個人に直接の利益はない。** 気分の改善、学習の向上、個別の助言のいずれも提供しない。
2. 想定される負担は、1日3分程度の入力時間、および通信量である。
3. 想定されるリスクは次のとおりである。
   1. その日の出来事を書くことで、思い出したくないことを思い出す可能性。書かない自由、途中でやめる自由により対応する。
   2. データの漏えい。第4部 4.8 の安全管理措置により低減するが、**ゼロにはできない。**
   3. 仮名化した記述であっても、記述内容の組み合わせから個人が推測される可能性。公表時に小集団が特定される集計を掲載しないことにより低減する。
4. 本研究は侵襲を伴わず、介入を行わない。身体的リスクは想定しない。

### 第13条（謝礼・費用）

1. **謝礼、金券、物品、成績上の利益のいずれも設けない。**
2. 参加に伴う通信費等は参加者の負担となる。実施者はこれを補償しない。
3. 本研究の参加に、参加者が実施者へ費用を支払うことはない。

### 第14条（保存期間）

| 対象 | 上限 | 起算点 |
| --- | --- | --- |
| 本文（暗号化列） | 90日 | 各記録の作成時 |
| 仮名化した研究データ・個票解析結果 | 1年 | 研究終了時 |
| 本人との対応表 | 90日 | 研究終了時 |
| 同意・撤回・削除の証跡（本文を含まない） | 5年 | 各処理の完了時 |

1. 期限到来後は削除する。削除の失敗を監視し、バックアップから復旧した場合は削除を再適用する。
2. バックアップ内の残存期間は、実際の設定を確認したうえで別途説明する。**本版では未確認である。**
3. 削除の実行日時・対象・実行者・検証結果を、本文を含まない形で記録する。

### 第15条（学習利用は別の任意であること）

1. 本文その他のデータを、将来のモデルの学習に用いることは、参加とは**別の任意**とする。
2. **既定は「使わない」である。** 選ばなくても本研究には通常どおり参加できる。

## 第5部 同意の取得方法と記録

### 5.1 同意の構成

同意は次の2群に分ける。

**A群：参加に不可分な事項（1つのボタンで一括して同意する）**

| # | 項目 | 保存先 | なぜ分離しないか |
| --- | --- | --- | --- |

**B群：任意の事項（既定オフのスイッチ。触れなくてもA群のボタンを押せる）**

| --- | --- | --- | --- | --- |

| B2 | 個人を識別できない形にしたデータを研究成果として外部に出すこと | `consent_records.anonymized_export` | オフ | 参加できる。当該参加者は外部公表用の集計から除外される |
| B3 | AIモデルの学習に使うこと | `consent_records.model_training_use` | オフ | 参加できる。学習に用いない |

### 5.2 「ボタンは1つ」の意味と、その適法性の根拠

1. 画面上、**押すべきボタンは「同意して開始する」1つだけ**とする。参加のために複数のボタンを順に押させない。
2. このボタンが記録するのは**A群のみ**である。B群は同一画面上の任意スイッチであり、既定オフのまま同意ボタンを押せる。
3. A群を1つのボタンに束ねてよいのは、A1〜A4が**同一の目的に不可分に結びついており、いずれかを欠くと本研究への参加が成立しない**ためである。参加の可否そのものが1つの選択である以上、これを複数のチェックに分割することは、理解を助けず、かえって形式的な操作を増やす。
4. 一方、B群を同じボタンに含めることはできない。B1〜B3は、**それぞれ同意しなくても本研究に参加できる**事項である。参加に不可欠でない事項への同意を、参加の条件と同じ操作に束ねることは、当該同意を任意といえなくする。とりわけB3（学習利用）は本研究の目的の範囲外であり、束ねた場合、取得した同意は利用目的の特定を欠くものとなる。
5. したがって本設計は、**「1回の操作で参加に同意でき、任意事項は既定オフのまま残る」**という形を採る。これは、長文の規約を1つの同意ボタンで受け入れさせつつ、解析データの送信等を別の任意設定として分離する一般的な実務と同じ構造である。
6. 撤回についても、**「研究への参加をやめる」1つの操作**で足りるものとする。撤回に際して理由の入力欄を置かない。

### 5.3 画面仕様

実装は次の各号を満たすこと。満たさない実装で取得した同意を有効なものとして扱わない。

1. 第1部〜第7部の全文を1枚のスクロール可能な領域に表示する。要約のみを表示して同意ボタンを有効化しない。
2. 同意ボタンは、表示領域の末尾へ到達するまで無効とする。到達の事実と時刻を記録する。
3. B群のスイッチは同意ボタンより上に配置し、**既定をオフ**とする。オンにする操作がなければオフのまま記録する。
4. 事前にチェック済みの状態、暗い配色や小さい表示によりB群を見落とさせる表現、A群とB群を視覚的に同格に見せない配置を用いない。
5. 同意ボタンの直上に、次の3点を1文ずつ、省略せずに表示する。
   1. 参加しなくても成績・評価・進路に影響しないこと。
   2. いつでも理由なくやめられること。
   3. 謝礼がないこと。

7. 18歳未満の場合、本画面の完了のみでは参加を開始しない。保護者の確認（第20条）が別トークンで記録されるまで、サーバ側で研究利用のフラグを保留する。
8. 参加者には、同意した内容をいつでも再表示・再確認できる画面を用意する。

## 第6部 撤回・削除・開示等の請求

### 6.1 撤回

**本人が撤回するとき**

1. アプリの設定画面から「研究への参加をやめる」を選ぶ。操作は1つとし、理由の入力欄を置かない。
2. 撤回の効果は次のとおりとする。
   1. 以後の記録を研究データとして保存しない。
   2. 撤回時刻以後の書き込みをエクスポートに含めない。
   3. アプリの通常利用は継続できる（継続するかどうかも自由である）。

**保護者、またはアプリを使用できない本人が撤回するとき**

1. blesc.jp@gmail.com、または協力校の指定担当者へ申し出る。
2. 電子メールは**受付のみ**とし、本人確認は既知の学校経路またはログイン済みの経路で行う。
3. 電子メールに、本文、健康・診断に関する情報、パスワード、確認用リンク、身分証の画像を送らないこと。
4. 本人確認を終えた撤回について、**1営業日以内**に研究利用を停止することを目標とする。

**撤回後の既収集データ**

| 選択 | 効果 |
| --- | --- |
| 残す | 撤回時点までのデータを解析に用いる |
| 削除する | 6.2の手続へ進む |

いずれを選んでも不利益はない。選択がない場合は「削除する」として扱う。

### 6.2 削除

1. 本人または保護者が、6.1の経路で削除を依頼する。
2. データ管理責任者が本人確認を行う。
3. 対象データを削除し、削除の事実・日時・対象・実行者・検証結果を、本文を含まない形で記録する。
4. 依頼者へ完了を通知する。

| 削除されるもの | 削除されないもの |
| --- | --- |
| 自由記述の本文（暗号化列を含む） | 削除を行ったという記録そのもの |
| 自己評定の回答 | 個人を識別できない集計値 |
| 記録の過程（入力所要時間等） | すでに公表された研究結果 |
| 仮名IDと本人の対応表 | 法令により保存が義務付けられる記録 |

### 6.3 開示等の請求

1. 4.9に掲げる請求は、6.1と同じ経路で受け付ける。
2. 本人確認の方法は6.1第2項と同じとする。
3. 開示は、請求者本人の分に限る。他の参加者のデータは開示しない。
4. 開示に手数料を要しない。

### 6.4 処理期限

| 手続 | 目標 |
| --- | --- |
| 受付確認 | 3営業日以内 |
| 本人確認済みの撤回による研究利用の停止 | 1営業日以内 |
| 稼働系からの対象データの削除 | 30日以内 |
| 開示請求への回答 | 30日以内 |

バックアップ内の残存期間は、実際の設定を確認して別途説明する。復旧を行った場合は削除を再適用する。

### 6.5 削除できないもの

**すでに公表した集計結果から、特定の個人の寄与を取り除くことはできない。** この制約は、第1部の要約、第2部第16条、第3部、および同意画面に明記する。削除できると説明したのちにできないと伝えることは行わない。

## 第7部 保証の限界・責任・準拠法

### 第24条（保証しないこと）

1. 実施者は、本研究の参加によって参加者の心身の状態が改善することを保証しない。
2. 実施者は、第10条の確認体制により、危険の発見および救助を保証しない。本研究は相談・救助・見守りの仕組みではない。
3. 実施者は、アプリが常時利用可能であることを保証しない。障害、保守、通信環境により利用できない期間が生じうる。
4. 実施者は、本研究の成果が特定の結論に至ることを保証しない。仮説が支持されない結果も、そのまま記録し公表する。

### 第25条（責任）

1. 実施者は、本研究の実施に関し、故意または過失により参加者に損害を与えた場合、法令に基づく責任を負う。
2. 本研究は無償であり、参加者に金銭的対価を求めない。
3. 実施者は、参加者の端末、通信環境、第三者の行為に起因する損害について責任を負わない。
4. 本条は、消費者契約法その他の強行法規により無効となる範囲では適用しない。

### 第26条（事故・中止）

1. 個人情報の漏えい、滅失、毀損その他の事故が生じた場合、[incident-runbook.md](incident-runbook.md) に従い、事実関係を確認し、本人および保護者へ通知し、法令に基づき個人情報保護委員会へ報告する。
2. 次の場合、実施者は本研究を中止する。中止した場合、全参加者へ通知する。
   1. 体制の不備（主担当・代替担当の双方の不在を含む）。
   2. 重大な障害または事故。
   3. 協力校からの中止の申出。
3. 中止した場合のデータの扱いは、6.1の撤回に準じ、各参加者が選択できるものとする。

### 第27条（本文書の改訂）

1. 本文書を改訂した場合、版名を変更する。
2. 同意の範囲を実質的に変更する改訂については、**改めて同意を取得する。** 旧版で取得した同意を新版の同意として扱わない。
3. 誤記の訂正その他、同意の範囲に影響しない改訂については、変更点を公開ページへ掲示する。

### 第28条（準拠法・管轄）

1. 本文書および本研究への参加に関しては、日本法を準拠法とする。
2. 本研究に関して紛争が生じた場合、参加者の住所地を管轄する地方裁判所、または東京地方裁判所を管轄裁判所とする。
3. 本条は、参加者が有する法令上の権利を制限するものではない。

### 第29条（分離可能性・言語）

1. 本文書のいずれかの条項が無効または執行不能とされた場合も、他の条項の効力に影響しない。
2. 本文書は日本語を正本とする。
