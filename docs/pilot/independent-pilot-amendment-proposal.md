- 研究責任者: 田雨竜（候補、本人受諾待ち）。データ管理責任者: 王謙蘊（候補、本人受諾待ち）。運用責任者: 梅澤透真（候補、本人受諾待ち）。ownerが2026-09-19に3名を指定した。
- 研究・データ管理・運用の主担当と代替、緊急時に使う連絡経路を非公開台帳に記録する。固定のレビュー時刻や30分の応答期限は設けない。担当・代替がともに不在で実際に覚知した危険へ対応できない状態なら収集を停止する。学校の担当・校内相談体制をI1の必須役割から外す。
- 3名へ同一の改訂版protocol・同意文書・変更一覧を送り、各人が担当受諾と両版の承認を明示的に返信する。記録には送信元メール、日時、版、承認意思、条件を保存する。返信での承認を文書承認完了の証跡とする場合、3名全員の返信が必要。送信だけ、開封だけ、ownerの代理返信だけでは完了としない。
- **文書承認完了と研究データ収集開始Goは別**。募集枠が埋まっていても、本人確認、保護者経路、画面/DBの版、削除、危機連絡、成人スタッフによる演習の証跡が揃うまで `draft` / No-Go。今回のメール承認だけで `recruiting` や `collecting` にしない。
- **現段階の文書策定、成人スタッフ・合成データによる検証、3名の内部承認に外部承認を一律の前提としない。** 実在する高校生の募集・研究データ収集を始める前には、研究目的・内容・実施主体に照らして適用される手続を確認し、判断の根拠を記録する。必要な手続が判明した場合にだけその手続を開始条件へ加える。3名の内部承認を外部審査の代替と称しない。
