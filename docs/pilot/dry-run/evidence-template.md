### 判定

| 役割 | 氏名 | 署名日 | 判定 |
| --- | --- | --- | --- |
| 研究責任者 | | | Go / No-Go |

**3名全員がGoでなければNo-Go。** 1名でもNo-Goなら募集を開始しない。

### No-Goの場合

- [#168](https://github.com/jbjgjf/BLESC/issues/168) を閉じない
- 失敗ごとに再現手順つきの修正Issueを作る
- 修正後、dry runを最初からやり直す
- **実在の高校生で失敗箇所を試さない**
