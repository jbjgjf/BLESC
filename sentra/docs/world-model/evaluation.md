# 評価仕様：動作することと、有効であることを分ける

[入口](README.md) / 版 `research-plan-v1`。T5は評価条件を先に固定し、T2〜T4の学習成果を独立に採点する。

## 72時間での受け入れ

1. fresh checkoutで記載コマンドが動き、鍵なしで合成データの学習・保存・再読込・推論・説明・評価まで完了する。
2. runごとにdataset/split/config/modelのhash、seed、依存環境、実測時間と利用量が残る。同じ設定で再実行し、宣言した許容差で一致する。
3. 欠測・空履歴・時刻ずれ・未来混入・schema不一致・未学習・API拒否・実行失敗が、契約どおり表現される。
4. 比較対象と新モデルの実測値が同じreportに入り、失敗・悪化も表示する。固定された成功値を返すfixtureだけでは合格しない。
5. 実行結果が研究画面に反映され、根拠参照・未検証の意味・不確実性の種類を確認できる。

以上は実装の受け入れ条件。新モデルの科学的優越性は別判定とし、改善がなければ仮説を支持しない結果として保存する。

## 独立した合成シナリオ

| シナリオ | 狙う失敗 | 比較 |
| --- | --- | --- |
| S1 安定した線形系 | 複雑なモデルが不要でも優れて見える | 持続値、訓練平均、線形自己回帰 |
| S2 現在値は同じ・履歴は異なる | 記憶を使わず同じ未来を返す | 履歴あり/なし |
| S3 積による高次相互作用 | 加算型で組合せを取り逃がす | pairwise-additive / interaction |
| S4 欠測と不規則時刻 | 欠測を0、7日を1日として扱う | mask/実経過時間の有無 |
| S5 未観測共通要因 | 相関を現実の因果と表示する | causal未対応の能力表示と仮定 |
| S6 言い換え・抽出器更新（次段階） | 同じ意味がモデル版だけで変動 | 固定アンカーを同じ版間で再評価 |

T5は生成器の真値・テストラベルを学習者の入力から隔離する。Day 3の最低対象はS1〜S5。生成機構、ノイズ、母数範囲と検証・テスト分割をH6までに固定し、成績を見て易しいテストへ変更しない。

## 分割と漏洩検査

参加者を跨ぐ汎化と、既知参加者の未来予測は別レポート。前者は参加者単位の分割、後者は時間の前後で分割する。合成では元軌道・パラメータ系列・言い換えの同一家族をsplit_groupにまとめる。
trainだけで正規化・特徴量選択・エンコーダーfitを行い、validationで設定を選択し、heldoutは最終採点にのみ使う。T2の自己教師あり事前学習にもheldoutを混ぜない。
全入力に `available_at <= cutoff_at` を要求する。未来の行を一行混ぜたテストが必ず失敗することを確認する。生成器seedが別でも、同じ軌道のコピーなら独立と扱わない。

## 測定する値

| 対象 | 指標 | 解釈上の条件 |
| --- | --- | --- |
| 連続値予測 | MAE/RMSE、モデルが分布を返す場合はNLL等 | 同じ単位・target・splitで比較する |
| 二値事象の予測 | Brier score $n^{-1}\sum(p_i-y_i)^2$ | 二値の独立した観測がある場合に限る |
| 予測区間 | 50/90%被覆率と平均幅 | 区間を広げただけの改善を防ぐ |
| 説明の忠実さ | paired rolloutの平均一致誤差、利用可能なら分布距離 | モデル内操作の範囲と推定方法を表示 |
| 構造回復 | precision/recall/F1、符号の一致 | 真の軸が既知の合成条件のみ。未整列の潜在軸で比較しない |
| 実装の健全性 | schema違反、未来混入、重複処理、権限拒否 | 正しく拒否するテストも必要 |
| 費用と速度 | 学習/推論時間、メモリ、API利用量 | 同じ実行環境で比較、計測不能はnull |

NLLは実現した観測の確率密度の負の対数。小さいほど観測に適した分布を置いたことを意味するが、連続値では単位の変更で値も変わる。MAEは誤差の絶対値の平均、RMSEは二乗誤差の平均の平方根。
precisionは予測した辺のうち正しい割合、recallは真の辺のうち回復した割合、F1はその調和平均。真の構造が定義できないケースでは計算しない。

## 事前に固定する実験

最低3つのseedを使い、全seedの値を保存する。これは再現性の初期点検で、十分な統計検出力を保証しない。参加者単位の集計を基本とし、長く書いた人が評価を支配しないよう集約を明示する。
比較セットは持続値、線形モデル、記憶モデル、説明射影あり/なし、積項あり/なし。計算量も報告する。予測の精度と説明の忠実さが相反する場合は、両方を表に残す。
合成の母数回復に必要な許容差はH6で生成器のノイズと数値精度から決める。未測定の性能値や「精度95%」を事前の完成条件にしない。契約の整合性は厳密な合否、科学的改善は比較結果と不確実性で判定する。

## 50人×21日へ進むとき

この3日間の完了で参加者募集は開始しない。既存のパイロットゲートとPR #138の実機確認は別に残る。モデルの学習利用許諾、独立した自己評定、測定頻度、モデル版の固定、基準質問、研究者のレビューを研究計画に記載する。
21日を14日+7日と分けても、7日で個人の複雑な因果モデルを検証できるとは限らない。50人の系列に対する実測可能性と不確実性を先に評価する。学習済み表現の適応と、基盤モデルのゼロからの学習を分ける。
適応質問や介入の実証は、固定された測定の対照と、質問提示自体の作用を扱う別の計画にする。Day 3の合成評価を臨床的有効性と呼ばない。
