## 1. 因果抽象化：可換であるとはどういうことか

**条件。** $\tau(F(h,a))\approx g(\tau(h),\omega(a))$。

**図で読む。** 縦が要約、横が時間発展である。

```
        F(・, a)
   h  ──────────▶  h'
   │               │
 τ │               │ τ
   ▼               ▼
   z  ──────────▶  z'
        g(・, ω(a))
```

右回り（先に動かしてから要約する）と下回り（先に要約してから動かす）が一致することを「可換」という。

**なぜこれを要求するか。** 一致しないなら、説明グラフ $g$ の上で語った話は、実際に予測している $F$ の振る舞いと対応していない。つまり説明が予測の説明になっていない。忠実さを予測精度と別に測るのは、この一致を独立に検査するためである。

**自明解に注意する理由。** $\tau\equiv\text{定数}$ と置けば、両辺とも同じ定数になり誤差は0になる。何も説明していないモデルが忠実度で満点を取る。したがって忠実さの指標は単独では使えず、次を同時に課す。

- $z$ から将来観測を予測できること（$z$ が情報を保っている）。
- $z$ が独立に測定された量と対応すること（$z$ に名前を付ける根拠）。

**破綻条件。** この可換性はモデル内の操作 $a$ について検証される。現実の人への介入で同じ関係が成り立つことの検証ではない。アプリ内でノード値を変更した結果は「モデル内シミュレーション」と表示する。

## 2. pushforward と Wasserstein 距離

**pushforward。** $(\tau_\#P)(B)=P(\tau^{-1}(B))$。「$P$ から $h$ を引いて $\tau(h)$ を見たときの分布」である。遷移が確率的なとき、比べる対象は点ではなく分布になる。

**$W_2$ の定義。**

$$W_2(P,Q)^2=\inf_{\gamma\in\Pi(P,Q)}\mathbb E_{(x,y)\sim\gamma}\lVert x-y\rVert^2$$

$\Pi(P,Q)$ は周辺分布が $P$ と $Q$ になる結合分布の集合である。$P$ の質量を $Q$ の形へ運ぶ最小コストを測っている。

**なぜKLダイバージェンスではないか。** KLは台が重ならないと発散する。二つの分布が離れているとき、KLは「どれだけ離れているか」を区別できず、いずれも無限大になる。$W_2$ は距離として有限の値を返し、勾配も得られる。

**閉形式。**

| 場合 | $W_2^2$ |
| --- | --- |
| 一次元の一般分布 | $\int_0^1\left(F_P^{-1}(u)-F_Q^{-1}(u)\right)^2du$ |
| 一次元ガウス | $(\mu_1-\mu_2)^2+(\sigma_1-\sigma_2)^2$ |
| 多変量ガウス | $\lVert\mu_1-\mu_2\rVert^2+\operatorname{tr}\left(\Sigma_1+\Sigma_2-2(\Sigma_2^{1/2}\Sigma_1\Sigma_2^{1/2})^{1/2}\right)$ |

一次元ガウスの式から、幅が等しい（$\sigma_1=\sigma_2$）とき $W_2=\lvert\mu_1-\mu_2\rvert$ が従う。[モデルの数学](math-models.md) に書いた例はこの特別な場合である。

**破綻条件。** 一般の分布ではサンプルからの推定が要り、標本数が少ないとバイアスが乗る。次元が上がるほど必要な標本数が増える。平均の二乗誤差だけを計算して $W_2$ と呼ばない。Day 3では、平均の一致誤差とサンプルによる分布比較を別々のメトリクスとして報告してよい。

## 3. ヤコビアンと高次相互作用

**定義。** $J_{jk}=\partial f_j/\partial z_k$。線形系なら $J=A$ で定数、非線形なら状態ごとに変わる。

**高次相互作用の見分け方。** $\dot z_3=az_1+bz_2+cz_1z_2$ のとき

$$\frac{\partial f_3}{\partial z_1}=a+cz_2$$

$z_1$ の効果が $z_2$ の値に依存する。つまり「ヤコビアンが状態に依存すること」が組合せ効果の signature である。$c=0$ なら効果は加算的で、ヤコビアンは定数になる。

**座標依存性。** 疎であるという主張は座標系に依存する。$z_1'=z_1+z_2$ と変換すると $z_1'^2=z_1^2+2z_1z_2+z_2^2$ となり、新しい座標での単純な二次項が、元の座標では相互作用項になる。したがって、変数の意味・単位・尺度を測定契約で固定してからでないと、疎性の比較に意味がない。

**破綻条件。** ヤコビアンは仮定した動的モデルの局所感度であって、人への介入効果ではない。可制御性の議論も同じで、仮定したモデルと許した入力に対する性質である。

## 4. 構造の事後分布：なぜ列挙できないか

**目標。** $p(G,\Theta,Z\mid\mathcal D)$ を、グラフ・係数・状態の不確実性を保ったまま扱う。

**規模。** ノード数 $n$ の有向非巡回グラフ（DAG）の個数は超指数的に増える。

| $n$ | ラベル付きDAGの個数 |
| --- | --- |
| 3 | 25 |
| 5 | 29,281 |
| 10 | 約 $4.2\times10^{18}$ |

列挙も、全候補にわたる正規化も不可能である。近似が必須になるのはこのためである。

**二つの近似。**

- MCMC：現在の候補から近傍へ移動し、受理確率を調整して目標分布へ収束させる。多峰なとき、モード間を移りにくい。
- GFlowNet：グラフを1辺ずつ組み立てる方策を、終端状態への到達確率が報酬に比例するように学習する。多様なモードを出しやすいことが動機である。

**命名規則の根拠。** 複数seedやbootstrapで候補が出現した頻度は、最適化のばらつきを表す量であって、事後分布からの標本ではない。両者は一般に一致しない。だから `bootstrap_frequency` のような名前で保存し、事後確率へ昇格させない。

**循環の扱い。** DAGは非巡回である。睡眠と負担が互いに影響し合う構造は、時間方向へ展開する（時刻ごとにノードを置く）などの設計変更なしには表現できない。

## 5. 識別可能性：観測が同じでも中身は違いうる

**定義。** パラメータ $\theta$ が識別可能とは、$p_\theta=p_{\theta'}\Rightarrow\theta=\theta'$ が成り立つこと。観測分布が同じなら中身も同じ、ということである。

**回転不定性（BLESCで最も効く例）。** 潜在変数 $h\sim\mathcal N(0,I)$、観測 $y=Wh+\text{雑音}$ とする。任意の直交行列 $R$ について $h'=Rh$、$W'=WR^\top$ と置くと

$$W'h'=WR^\top Rh=Wh$$

であり、$h'$ も $\mathcal N(0,I)$ に従う。つまり $y$ の分布は完全に同じで、潜在軸だけが回転している。**観測からは潜在軸の向きを決められない。**

これが「$h$ の各成分をそのまま特定の感情と名付けない」という規則の数学的な根拠である。規約の問題ではなく、観測から決まらない量に名前を付けているという問題である。

**スケール不定性。** $h\to2h$、$W\to W/2$ でも $y$ は同じ。大きさも決まらない。

**識別するために要る追加条件。** 潜在変数の非ガウス性（独立成分分析の系統）、疎性の制約、補助変数、複数環境での不変性など。LeJEPAの識別に関する結果もこの系統で、定常性や潜在分布についての条件が付く。条件が成り立つかは対象データごとに確かめるべきことで、定理を引用して成立を主張することはできない。

**BLESCでの運用。** 21日×50人でこれらの条件が満たされる保証はない。したがって $z$ の名前は、独立に測定された量との対応と評価結果に基づいて付ける。これが既存方針の理由である。

## 6. 交絡と $do$：数値で見る差

**区別。** $p(y\mid x)$ は「$x$ という値が観測された人たち」の $y$ の分布。$p(y\mid do(x))$ は「全員に $x$ を設定した」ときの $y$ の分布。

**設定。** $c$ を試験期間（$P(c=1)=0.4$）、$x$ を睡眠不足、$y$ を負担高とする。試験は睡眠と負担の両方に効くが、**睡眠から負担への因果効果はゼロ**とする。

| 条件 | 値 |
| --- | --- |
| $P(x=1\mid c=1)$ | 0.8 |
| $P(x=1\mid c=0)$ | 0.2 |
| $P(y=1\mid c=1)$ | 0.7（$x$ に依存しない） |
| $P(y=1\mid c=0)$ | 0.2（$x$ に依存しない） |

**観測される関連。** $P(c=1\mid x=1)=0.32/0.44=0.73$ より

$$P(y=1\mid x=1)=0.73\times0.7+0.27\times0.2=0.56$$
$$P(y=1\mid x=0)=0.14\times0.7+0.86\times0.2=0.27$$

差は **29ポイント**。相関だけを見れば「睡眠不足が負担を強く上げる」という強い関連が出る。

**バックドア調整。** $c$ を測っていれば $p(y\mid do(x))=\sum_cp(y\mid x,c)p(c)$ で計算できる。

$$P(y=1\mid do(x=1))=0.7\times0.4+0.2\times0.6=0.40$$
$$P(y=1\mid do(x=0))=0.7\times0.4+0.2\times0.6=0.40$$

差は **0ポイント**。設定どおり因果効果はない。

**この例の含意。** 29ポイントの関連と0ポイントの効果が同じデータから出る。観測期間中の予定・試験のような共通原因を測定項目に含める設計判断は、この計算を可能にするためのものである。$c$ を測っていなければバックドア調整は実行できず、29ポイントを因果効果と区別する手段がない。

**破綻条件。** 未測定の交絡が残る場合、調整では対処できない。感度分析（「どれだけ強い未測定交絡があれば結論が覆るか」）を併記する。

## 7. 部分識別：データを増やしても縮まない不確実性

**定義。** 仮定と観測に整合するモデルの集合を $\mathcal M(\mathcal D)$ とし、知りたい効果 $Q$ について $\left[\inf_{M\in\mathcal M(\mathcal D)}Q(M),\ \sup_{M\in\mathcal M(\mathcal D)}Q(M)\right]$ を報告する。

**信用区間との違い。** ここが混同されやすい。

| | 何による不確実性か | データを増やすと |
| --- | --- | --- |
| 事後信用区間 | 一つのモデルの中での推定誤差 | 縮む |
| 部分識別の区間 | データと仮定に合うモデルが複数あること | 縮まない |

有限データの推定誤差は、部分識別の区間とは別に考慮する。両方を混ぜて一つの区間として表示しない。

**BLESCでの意味。** 「因果を発見した」と言えない理由を、感想ではなく形式的に述べられるようにするための道具である。仮定を追加すれば区間は狭くなるが、狭くしたのは仮定であってデータではない。追加した仮定を明示する。

## 8. 欠測が状態に依存する場合（MNAR）

**分解。** 記録の有無 $M$ と内容 $y$ を分けて

$$p(M\mid h,\text{予定},\text{負担})\ p(y\mid h,M=1,\text{質問})$$

と置く。

**分類。** 欠測が観測済みの変数だけで説明できるならMAR、未観測の状態 $h$ に依存するならMNARである。つらい日ほど日記を書かない、という機構はMNARである。

**なぜ難しいか。** MNARでは、観測されたデータに同じくらいよく適合する複数の欠測機構がありうる。同時モデルを書き下すこと自体は誰でもできるが、それだけでは識別できない。補助情報、実験的な設計（記録を促す介入の無作為化など）、感度分析のいずれかが要る。

**運用。** 欠測率と欠測パターンを参加者ごとに報告し、欠測を平均値で埋めた結果を観測と同列に扱わない。イベントの発生時刻と、本人が記録した時刻と、記録しなかった過程は、それぞれ別の量として保存する。

## 9. 較正と被覆率：どこからが外れか

**被覆率。** 90%予測区間に実際の観測が入った割合。

**素朴な計算。** 1,050観測で被覆率90%なら、期待は945件。二項分布の標準偏差は $\sqrt{1050\times0.9\times0.1}=9.7$ なので、926〜964件はばらつきの範囲に見える。

**この計算は誤っている。** 同一参加者の日次観測は独立ではない。級内相関を $\rho$、1人あたり $m$ 日とすると、実効サンプルサイズは

$$n_{\text{eff}}=\frac{nm}{1+(m-1)\rho}$$

$\rho=0.5$、$m=21$、$n=50$ なら $n_{\text{eff}}=1050/11\approx95$。1,050ではなく約95である。被覆率の標準誤差は $\sqrt{0.9\times0.1/95}=3.1$ ポイントで、素朴な計算の0.93ポイントの3倍以上ある。狭すぎる区間で「較正できている」と判定しない。

**幅とのトレードオフ。** 区間を極端に広くすれば被覆率は上がる。したがって被覆率だけでなく、区間幅、および proper scoring rule（CRPS、pinball loss など）を併記する。較正と鋭さを同時に見る。

**表示規則。** 何についての区間か（将来観測か、パラメータか）と、どの方法で作ったか（ベイズ信用区間か、頻度論の信頼区間か、分位点回帰か）を必ず併記する。

## 10. bootstrap の単位

**手順。** 標本の単位を復元抽出し直して、推定量のばらつきを調べる。

**縦断データでの誤り。** 日記を1件ずつ独立に再抽出すると、同じ参加者の日が再標本の中でばらばらになる。個人内の依存が壊れ、ばらつきを系統的に過小評価する。信頼区間が実際より狭くなる。

**正しい単位。**

- 参加者単位（cluster bootstrap）：参加者をまるごと復元抽出する。
- 連続ブロック（block bootstrap）：時間的な依存を保つため、連続した日の塊を単位にする。

**分割にも同じことが言える。** 日ごとのランダム分割は、同じ人の将来を訓練データへ混ぜる。参加者単位、または時間で切る分割を使う。これは [受け渡し仕様](https://github.com/jbjgjf/BLESC/wiki/Research-Contracts) の分割マニフェストで固定する。

**破綻条件。** 参加者50人ということは、cluster bootstrap の実質的な標本数が50である。この規模でのばらつき推定はそれ自体が不安定なので、区間を過度に細かく解釈しない。

## 11. この文書に対応する検証項目

T4・T5の受け入れ確認で、次を実験マニフェストに残す。

- 忠実度の指標と併記した、$z$ からの予測性能および独立測定との対応（$\tau$ が自明解でないことの証拠）。
- $W_2$ をどう計算したか（閉形式か、サンプル推定か、標本数はいくつか）。
- 構造候補の頻度を `bootstrap_frequency` として保存し、事後確率と呼んでいないこと。
- 潜在軸に名前を付けた場合、その根拠となる独立測定。
- バックドア調整に使った変数と、未測定交絡についての感度分析。
- 被覆率の評価に使った実効サンプルサイズと、bootstrap の再標本単位。
