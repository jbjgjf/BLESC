## 研究設計の前提（#315 / PR #328）

- **50名 × 28日、区分なし、1日1件。最大 1,400件。** PR #328（#315）の内容であり、**2026-10-11 時点で main に入っていない。** main の `docs/pilot/protocol.md` は 50名 × 21日（14日 + 7日）のままである。ここでは #315 で 2026-10-04 に決まった 28日を前提にする。#328 が変わったら、この節と `data_sufficiency.PILOT_STUDY_DESIGN` を一緒に直す。
- **実効サンプル数は 1,400 ではない。** 同じ生徒の日々は互いに似ている。級内相関 ρ のもとで、参加者 *i* の *m_i* 日は独立な観測 *m_i* / (1 + (*m_i* − 1)ρ) 件分にあたる。ρ = 0.5 なら 1400 / 14.5 ≈ **97**。ρ = 0.3 で約154、ρ = 0.7 で約70。ρ = 0.5 は計画上の仮置きで、測った値ではない（S2-13）。
- **参加者間の分散を推定できる単位は 50 である。** 部分プーリングの強さを決める参加者間のばらつきは、参加者の数でしか推定できない。日数を増やしても増えない。
- **1日1件は、#62 が調べた中で最も疎な密度である。** その密度では、決定論的な信号の検出 AUROC は約 0.74 で頭打ちになった（`data_sufficiency_study.md` Result 2）。

### 各項目で決めること

決める人が見落とさないための問いである。答えではない。「例」は選んでいない。

- **S2-01 推定対象。** 参加者ごとの何を推定するか（例: Reflection Signal が使う日次特徴量の、参加者ごとの平均と散らばり）。点推定ではなく事後分布として返すこと、どの日の、どの特徴量についての量かを書く。
- **S2-02 非診断の用途。** 誰が、何のために使い、**何に使わないか**。教職員向けに出すのか、研究の解析だけか。リスク区分・診断・選別に使わないことを、用途の側から書く。
- **S2-03 尤度。** 特徴量ごとの分布族とリンク。件数（`state_count` など）、比率（`protective_ratio` など）、常に0の特徴量（`event_avg_duration`、#62 の追補5）をどう扱うか。
- **S2-04 事前分布。** 各パラメータの尺度と、その根拠。合成データから推定した値は根拠にできない（確定事項2）。参加者間の分散の事前分布は、参加者が50名しかいないために結果を左右しやすい。その感度を S2-10 で調べること。
- **S2-05 参加者効果の構造。** 切片だけか、傾き（時間の効果）も入れるか、曜日を入れるか。28日は4週ちょうどなので、各曜日が参加者ごとに4回ずつある（PR #328）。
- **S2-06 欠測の仮定。** 書かなかった日を、ランダムな欠測（MAR）とみなせるか。調子の悪い日に書かないなら MAR ではない。MNAR の感度分析の方法を決める。欠測を0で埋めない（#102 の不変条件）。
- **S2-07 評価分割の方式。** 参加者単位の分離は確定している（確定事項3）。何分割か、層別の有無、1参加者の中で時間順に予測を評価するか（前方への評価）を決める。
- **S2-08 事後予測チェック。** どの統計量を見るか（例: 参加者ごとの平均・分散・自己相関、0の割合）。合格の条件。
- **S2-09 較正の基準。** 区間の被覆率の目標と許容幅。**標準誤差は実効サンプル数で計算する。** 90%区間の被覆率を n_eff ≈ 97 で見ると、標準誤差は約3.0ポイントになる（1,400件として計算した約0.8ポイントの3倍以上）。狭すぎる幅で「較正できている」と判定しない。
- **S2-10 感度分析。** 事前分布、ρ、欠測の仮定を、どの範囲で動かすか。結論が変わったときにどう報告するか。
- **S2-11 プーリングが弱まることの確認。** 観測日数が増えるにつれて、個人の推定が全体の平均から離れて個人のデータに寄っていくことを、何で確かめるか（例: 縮小係数を日数ごとに示す）。
- **S2-12 必要な観測量。** 参加者数の下限、1人あたりの日数の下限、実効サンプル数の下限。`learning_gates.STAGE2_OBSERVATION_REQUIREMENT` に入れ、`decided_in` にこの文書の版を書く。50名・28日・n_eff 約97（ρ = 0.5）を超える値は、この研究設計では満たせない。その場合は `requirement_exceeds_design` で閉じる。
- **S2-13 計画上の級内相関。** 計画用に ρ = 0.5 を仮置きしている（`data_sufficiency.PLANNING_ICC`）。この値を使うか。実データから ρ をどう推定するか。推定した区間の上端で置き換えるか。
- **S2-14 必要な同意の範囲。** 同意記録の `research_analysis` だけで足りるか、`model_training_use` も要るか。未成年者の本人同意と保護者同意の扱い。撤回した参加者の記録を数えない方法。
- **S2-15 承認の主体と記録の置き場所。** どの委員会・担当者が承認し、記録をどこに置くか。`docs/pilot/approvals.md` の承認は研究protocolと同意文書の承認であり、この分析の承認ではない。
