## 0. お願いしたいこと

**質問は2つだけです。** 設計をお願いするものではなく、**既に決めた設計が妥当かどうかの
判断**をいただきたい、というのが依頼の全体です。事前に読んでいただく必要はありません。

## 1. この製品が「やること」と「やらないこと」

**リスク判定は行いません。** 教員画面の「リスク:高/中/低」は 2026-08-06 に廃止しました。
理由は検証不足ではなく算術です — 1000人・有病率5%の学校で感度80%/特異度90%の分類器は
135人に印を付け、うち95人は該当しません（的中率30%）。モデルを改善しても消えない性質
なので、表示自体をやめました。教員が見るのは**観測された事実とその時刻**だけです。

今回ご相談する因果まわりの出力も、**教員には一切出していません**。内部の探索的な数値です。

## 3. 因果に関係する実装の現状

### 3-1. 抽出されるグラフ

エントリ1件ごとに LLM が概念と関係を抽出します。関係の語彙は6種：

```
causes / escalates / buffers / avoids / co_occurs / precedes
```

**これは統計的推論ではありません。** 生徒本人が語りの中で述べた帰属を、そのまま型付けして
写しているだけです。1件の日記から `causes` が付きます。

未知の値は既定で `co_occurs`（最も弱い主張）に降格し、降格したことを記録します
（`ontology/validator.py`、silent な置換を廃止済み）。

### 3-2. 関係の型と根拠の強さを分離している

`ontology/schema.py` は関係の型とは別に `EvidenceStrength` を持ちます：

```
causal / association / expert_judgement
```

**型が `causes` でも強さは `association`** という組み合わせを正規の状態として許しています。
文献が関連しか報告していないのに型だけ因果にすると、その差が消えるためです。

### 3-3. キュレーション済みサブグラフ（`ontology/seed/sleep.yaml`）

当社サイトが例示していた 睡眠不足 → 認知機能の低下 → 抑うつ傾向 の連鎖。12ノード15エッジ。

| | |
|---|---|
| 出典に依拠 | 9（すべて `association`） |
| **出典なしの判断** | **6（40%）** |
| `causal` を主張するもの | **0** |

**40%は下げていません。**もっともらしい引用を各エッジに付けることは可能でしたが、機械可読な
形で露出させる方を選びました。

**意図的に循環を入れてあります**：`睡眠不足 → 抑うつ` と `抑うつ → 睡眠不足` の両方。
NG134 が睡眠障害を抑うつの特徴として挙げている以上、一方向だけ持つと文献を誤って
一方向的に表現することになる、という判断です。

方向を支持できないものは `precedes`（時間順序のみ、因果の主張を明示的に含まない）に
降格しています。

### 3-4. 時系列側（`analytics/dynamics.py`）

分散と lag-1 自己相関を、**その参加者自身の系列に対してのみ**計算します。母集団分布は
一切参照しません（`POPULATION_BASELINE` は削除済み、復活させるとテストが落ちます）。

critical slowing down から発想を借りていますが、**この集団で臨床的な意味があるという検証は
していません**。`NOT_VALIDATED_HERE` を全出力に同梱しています。

パラメータは結果を見る前に確定・文書化済み（事前登録の趣旨）。

### 3-5. 合成データでの感度研究

実データが無いため、生成過程を自分で書いた合成参加者 10,080 run で解析側の性質を調べました。

- ベースライン推定誤差は**厳密にサンプリングノイズ**（`0.798/√n`、全窓で誤差2%以内）
- 14日という既存の窓は、事前宣言した基準で妥当
- ただし**律速はデータ量ではありませんでした** — 何も起きていない参加者に対する誤検知が
  10日あたりで頭打ちになり 6〜9% に留まる

## 4. 質問（2つ）

### Q1. 「本人の語りに現れた因果的帰属」を、製品として何と呼ぶべきですか

3-1 のとおり、`causes` エッジは統計的因果推論の出力ではなく、生徒の語りの写しです。
型と根拠の強さは分離してありますが、**呼び方の線引きが自分たちでは決められません。**

- 統計的因果探索の語彙で言うと、これは何にあたるのか。そもそも「因果グラフ」と
  呼んではいけないのか
- 画面・サイト・提出書類で**使ってよい言葉／絶対に使ってはいけない言葉**を、具体的に
  線引きしていただきたい
- 方向が支持できないものを既定で `precedes` に降格する運用は妥当か。それとも
  「本人の帰属」であること自体を型として持つべきか（例：`attributed_by_participant`）

### Q2. この条件で因果方向は原理的に扱えますか。扱えないなら、代わりに何を測るべきですか

条件は **個人内・N=1・最長7観測点・不等間隔（隣接日ゼロ）・潜在交絡あり**です。

具体的にお聞きしたい点：

- VAR-LiNGAM 等が要求する**最低限の系列長と等間隔性**はどの程度か。7点・隣接日0 が
  論外なのは分かるので、**何点あれば入口に立てるのか**を知りたい
  （この数字がそのままデータ収集設計になります）
- 非ガウス性の仮定は、床効果・打ち切りのある心理状態の変数で成り立つのか
- 潜在交絡（試験期間・長期休暇・学校行事・季節）は個人内 N=1 でどう扱うのか。
  時間トレンドを共変量に入れる程度で足りるのか
- **「因果方向は諦め、個人内の時間順序と予測可能性だけを主張する」設計に落とすのは、
  研究として筋が通るか。**筋が通るなら、その場合に主張してよいことの上限はどこか
- 3-3 の循環を含む文献由来グラフを、探索手法の**事前知識**として使う筋道はあるか

## 5. お願いしないこと

- 製品の妥当性の**保証**
- 生徒データへのアクセスを伴う判断（そもそも実生徒データがありません）
- 臨床的な診断・判定への関与
- 継続的なコミットメント（今回は30分の単発です）
