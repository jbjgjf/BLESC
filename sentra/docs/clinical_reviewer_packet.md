## 1. この製品が「やること」と「やらないこと」

まず前提として、**リスク判定は行いません。**

教員の画面に「リスク:高/中/低」を出すことは 2026-08-06 に廃止しました。理由は検証不足ではなく算術です。1000人・有病率5%の学校で、感度80%/特異度90%の分類器は135人に印を付け、うち95人は該当しません（的中率30%）。モデルを良くしても消えない性質なので、表示自体をやめました。

いま教員が見るのは**観測された事実とその時刻**だけです。

```
3年2組 #14   要確認
  観測: 自傷に関する直接的な表現（8/3 22:14）
        └ 根拠: 決定的な語句マッチ / 推論なし
  文脈: 基準値の学習中（残り6日）· この期間は比較を表示しません
  注意: 本ツールは診断を行いません
```

「死にたいと書いた」は検証不要の事実、「リスク:高」は検証必須の推論、という切り分けです。詳細は `educator_display_policy.md`。

**今回ご相談する指標も、教員には出していません。** 内部の探索的な数値です。

## 4. 質問（2つ）

### Q1. 30秒間の自由再生は、この構成概念の誘発法として妥当ですか

生徒に「30秒で思い浮かんだことを書いてください」と促し、その記述の語彙密度から算出しています。

- RRS は「落ち込んだとき、あなたはどうしますか」と**特性**を尋ねます
- 本製品は**その時点の記述**を測っています

これは同じものを測っていると言えるのか、それとも別物か。**別物であれば、それでも意味のある descriptive signal になりうるか**をお聞きしたいです。

### Q2. 2成分に分けた設計は妥当ですか（分けるべきか、ではなく）

**分離は既に実装済みです。**「1つのスカラーにすべきか」という開いた問いではなく、**この分け方でよいか**をご判断ください。

```
negative_self_focus_score = (ネガティブ語密度 + 一人称密度 + 反復率) / 3
reflective_focus_score    = 内省語密度
合成スカラーは出力しない
```

分離した理由は、RRS が brooding と reflection を別々に報告し、臨床的意義が異なるためです。旧実装は3成分すべてが brooding 側で、両因子を名乗りながら実質 brooding 単独でした。

合成値を出さないのは、平均すれば分離が打ち消される上、両者の重み付けに根拠がないためです。

**具体的にお聞きしたい点：**
- brooding 側の3成分（ネガティブ語・一人称・反復）は妥当か。過不足はないか
- reflection 側を語彙密度だけで測るのは粗すぎないか
- 合成値を出さない判断は妥当か
