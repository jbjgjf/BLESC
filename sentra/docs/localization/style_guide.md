# 日本語スタイルガイド

このスタイルガイドは、BLESC-website を基準とし、日本の学校関係者（生徒、教員）が自然に理解できる日本語 UI を構築するための基準を定めます。

## 基本方針
- 簡潔で落ち着いた、自然な敬体（です・ます調）を基本とする。
- 英語の構文や名詞をそのまま移した「翻訳調」を避ける。
- 必要のないカタカナ語・専門用語を避け、学校現場で通じる表現を優先する。

## 対象読者別のトーン
### 生徒向け
構えずに読める言葉を使います。
- ◯ 「今日の気分はどうですか？」
- ✕ 「現在の心理状態を入力してください」

### 教員向け
判断や行動につながる明確な言葉を使います。
- ◯ 「要注意の生徒が1名います」
- ✕ 「アラートが1件発生しました」

## 回避すべき表現（NGワード）
AI が心理状態を診断・断定するように読める文言は絶対に使用しないでください。
「心理的リスクの判定は行いません」「会話の内容そのものは教員に公開されません」といった安全・プライバシー説明と矛盾しないようにします。

| NG表現 | 理由 | 代替表現の例 |
| :--- | :--- | :--- |
| 診断する、判定する | 医療行為と誤認されるため | 振り返る、分析する、傾向を見る |
| 異常、リスクがある | 不安を煽るため | 気になる点、サポートが必要な可能性 |
| 確実です、〜に違いありません | AIの推論は不確実なため | 〜の傾向が見られます、〜かもしれません |
