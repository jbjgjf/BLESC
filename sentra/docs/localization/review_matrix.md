# 翻訳レビューマトリックス

各画面の文言抽出と翻訳、レビューの進捗を管理する表です。

## ステータス定義
- `未` : 未着手（英語のまま、または抽出のみ）
- `初稿` : 一次翻訳完了
- `文脈` : 画面に当てはめて文脈確認済み
- `完了` : 最終確認（スタイルガイド準拠）済み
