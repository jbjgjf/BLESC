# 翻訳レビューマトリックス

各画面の文言と、その日本語のレビュー状況です。

`sentra/frontend` の全画面を機械的に走査して作成しました（`npm test` の
「Japanese UI」テストが同じ走査を実行しています）。走査対象は `src` 配下の
`.tsx` / `.ts` で、除外したモジュールは `scripts/ui-strings.mjs` の
`MACHINE_MODULES` に理由つきで記載しています。

## ステータス定義
- `未` : 未着手（英語のまま、または抽出のみ）
- `初稿` : 一次翻訳完了
- `文脈` : 画面に当てはめて文脈確認済み（実機での目視は未実施）
- `完了` : 実機で確認し、スタイルガイド準拠を確認済み

## 文言の置き場所

画面に出る文言はメッセージカタログ `src/lib/i18n/ja.ts` にあります。表の
「カタログ」列は、その画面の文言がカタログに移されているかを示します。移行前の
画面は日本語ではあるものの、文言がファイル内に直接書かれています。

## 残っている作業

カタログ移行は 2026-09-10 に完了しました。上表の「カタログ」列に「未」「一部」
はもう残っていません。残りは、コードを読むだけでは終わらない 2 つです。

- **実機での確認（`完了` への引き上げ）**: 全画面をデスクトップとモバイルで開き、
  文字切れ・折り返し・ボタン幅・読み上げラベルを確認する。表の `文脈` は
  「コードを読んで文脈を確認した」段階で、画面での目視はまだです。移行で表示
  文字列は変えていないので、移行前後で見え方は変わりません。
- **学校関係者によるコピーレビュー**: 生徒向け・教員向けそれぞれの導線を、
  実際の学校の方に読んでいただき、指摘を反映する。

### 移行で分かったこと

`/educator/alerts`・`/educator/class`・`/educator/meetings`・`/school` の 4 画面は、
企画書の固定データで動くデモ専用の画面です（`AppNav` の `DEMO_ONLY_NAV_PATHS` に
入っており、通常のナビゲーションには出ません）。この 4 画面は生徒ごとのリスク
バンド（`blesc/labels.ts` の `BANDS`、および `TRENDS` の「悪化傾向 / 改善傾向」）を
描画しており、`docs/educator_display_policy.md` の規則 1 に反しています。

文言は `educatorDemo.*` へ移しましたが、**バンドの是非はローカライズの範囲外**
なので、別の issue として起票しています。画面を作り直すときは、`educatorDemo.*`
も一緒に書き直すことになります。

なお `educator_display_policy.md` 自身が「a policy enforced in one of two
implementations is not enforced」と書いています。これはその 2 例目です。
