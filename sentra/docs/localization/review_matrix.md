# 翻訳レビューマトリックス

各画面の文言と、その日本語のレビュー状況です。

`sentra/frontend` の全画面を機械的に走査して作成しました（`npm test` の
「Japanese UI」テストが同じ走査を実行しています）。走査対象は `src` 配下の
`.tsx` / `.ts` で、除外したモジュールは `scripts/ui-strings.mjs` の
`MACHINE_MODULES` に理由つきで記載しています。

## ステータス定義
- `未` : 未着手（英語のまま、または抽出のみ）
- `初稿` : 一次翻訳完了
- `文脈` : 画面に当てはめて文脈確認済み（実機での目視は未実施）
- `完了` : 実機で確認し、スタイルガイド準拠を確認済み

## 文言の置き場所

画面に出る文言はメッセージカタログ `src/lib/i18n/ja.ts` にあります。表の
「カタログ」列は、その画面の文言がカタログに移されているかを示します。移行前の
画面は日本語ではあるものの、文言がファイル内に直接書かれています。

## 残っている作業

- **実機での確認（`完了` への引き上げ）**: 全画面をデスクトップとモバイルで開き、
  文字切れ・折り返し・ボタン幅・読み上げラベルを確認する。表の `文脈` は
  「コードを読んで文脈を確認した」段階で、画面での目視はまだです。
- **カタログ移行の残り**: 上表で「未」「一部」の画面。文言はすでに日本語なので
  表示は変わりませんが、用語の統一と将来の英語版のために移します。
- **学校関係者によるコピーレビュー**: 生徒向け・教員向けそれぞれの導線を、
  実際の学校の方に読んでいただき、指摘を反映する。
