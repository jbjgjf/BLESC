# 研究runの設定

| ファイル | 用途 | 目安時間 |
| --- | --- | --- |
| `smoke.json` | Day 3の受け入れに使う既定設定。S1〜S5×3seed。 | CPUで約60秒 |
| `ci.json` | CIの経路確認用。S1とS3×1seed、学習は短い。 | CPUで約2秒 |

`ci.json` は**経路が通ることだけ**を確認する設定で、その数値をモデルの性能として
読まない。seedが1つ、参加者が12人、学習が40 epochでは、比較の差が偶然の範囲に
入る。性能を読むのは `smoke.json` の結果であり、そこでも3seedは統計的検出力の
保証ではなく再現性の初期点検である。

新しい設定を足すときは `config_id` を変える。同じ `config_id` で中身を変えると、
`config_hash` が変わっているのに人が読む名前は同じという最悪の組み合わせになる。
